Chain of custody — proving the evidence never changed

Every file is fingerprinted with SHA-256 and MD5. The fingerprint is re-computed at each stage and must match the first one.

Acquisition

Hash of the exact bytes received. This is the baseline every later check compares to.

⛓️HOW THE LEDGER DETECTS TAMPERING

#1 Acquisition
file SHA-256 9c1e…
previous —
entry hash A7F2…
🔗
#2 Pre-analysis
file SHA-256 9c1e… ✓
previous A7F2…
entry hash 3B90…
🔗
#3 Report ⚠️
someone edits entry #2
→ its hash is no longer 3B90…
link broken → detected
Each entry records the analyst, time, stage and hashes, plus the hash of the entry before it. Changing any past entry breaks every link after it. If any re-computed file hash differs from the baseline, analysis and reporting are blocked.

🚦STATUS OF EACH CHECK

🔵 RECORDEDFirst hash of a new file (the baseline)
🟢 MATCHRe-computed hash equals the baseline
🔴 MISMATCHFile changed → work is blocked and logged
🟠 NOT ACCESSIBLEFile missing or unreadable at check time
