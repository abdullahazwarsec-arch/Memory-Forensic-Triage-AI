MemTriage XAI — how the tool works

Give it a Windows memory dump → it finds signs of malware, explains why, and proves the evidence was never changed.

🎓Final-year project
{{logo:streamlit}} streamlit run app.py · localhost:8501
🗂️
STEP 1

Open a case

Who is investigating, which case, and when.
  • Case number + analyst name (required)
  • Unit and notes (optional)
  • Open / close time saved in local time and UTC
  • Nothing else unlocks until a case is open
📁outputs/cases/<case>/case.json
📥
STEP 2

Load evidence

Choose one of three inputs:
🧠
Memory dump
.raw .mem .vmem .dmp — upload (≤ 8 GB) or file path
📄
Volatility CSV
55 feature columns, 1 row per snapshot
🧪
Sample profile
ready-made demo files
  • Fingerprinted on arrival (SHA-256 + MD5) and given an evidence ID
{{logo:windows}} Windows images only
🔬
STEP 3

Extract features

Turn gigabytes of RAM into 55 numbers.
  • Volatility 3 identifies the Windows kernel, then runs 9 plugins
  • pslist dlllist handles ldrmodules malfind psxview modules svcscan callbacks
  • Counts processes, DLLs, handles, injected code, hidden processes, services, drivers
CSV and sample inputs already contain the 55 features, so they skip this step.
🧬Volatility 3
{{logo:pandas}} pandas
🤖
STEP 4

AI detection

Two models look at the same 55 numbers.
  • 🌲 Random Forest — 150 decision trees vote: malware score 0–100%
  • 🛰️ Isolation Forest — “have I ever seen anything like this?” Flags possible zero-day outliers
  • Score → risk level: NORMAL, SUSPICIOUS or HIGH RISK
{{logo:scikitlearn}} scikit-learn
{{logo:numpy}} NumPy
💡
STEP 5

Explain the verdict

Show why, in plain English.
  • SHAP — how much each memory clue pushed the score up or down (top 10)
  • LIME — simple “if … then” rules around this snapshot (top 8)
  • Two methods cross-check each other
  • Red = toward malware, blue = toward clean
📊SHAP
🍋LIME
📈Altair
📑
STEP 6

Report & seal

Everything an investigator hands over.
  • PDF incident report: verdict, reasons, all hashes, custody ledger
  • The PDF’s own hash is recorded (.sha256 file)
  • Custody manifest (JSON) per evidence item
  • Every action written to the audit log
