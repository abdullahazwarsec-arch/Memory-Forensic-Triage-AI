## What these numbers mean

- Grouping by sample changes the binary score very little, and even unseen families are detected. That is **not** proof of a general malware detector: one rule, `svcscan.nservices <= 390.5`, already scores 99.66 %. Every benign snapshot has 388-395 services because all benign data comes from one machine, so the model largely learns "different from that machine".
- Without the svcscan features the grouped score is 99.93 % - other counts (handles, DLLs, mutants) carry the same machine fingerprint.
- Expect false alarms on clean dumps from other Windows versions or machines. The benign rows carry no sample id, so they could not be grouped; a fair benign estimate needs dumps from many machines.
- The malware-type model is a hint, not a verdict: about 67.61 % correct on unseen samples.
